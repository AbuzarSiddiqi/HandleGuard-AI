Enterprise Engineering & Platform
Technical Architecture & Technology Stack
Zero-Cloud Latency, Privacy-First On-Premise Computer Vision Engine

Computer Vision

Optical Flow Blob Clustering Spatio-Temporal Tracking

Multi-scale temporal differencing with spatial clustering. Fuses optical blobs into unified large entities (e.g. mattresses) with CCTV interface masking.

AI / Machine Learning

COCO-SSD MobileNet-v2 Kinematic Rules

Client-side WebAssembly/WebGL accelerated neural object detection coupled with a 12-rule physics engine evaluating release velocity, drop height, and posture.

LLM & SOP Copilot

Grounded RAG SOP Retrieval Root-Cause Analysis

Grounded Retrieval-Augmented reasoning engine providing instant supervisory answers, incident breakdowns, and customized SOP retraining recommendations.

Video Processing & Privacy

HTML5 Canvas OffscreenCanvas Biometric Pixelation

60 FPS rendering pipeline with sub-pixel sampling, asynchronous range-request HTTP streaming, and dynamic operator facial blurring for strict privacy compliance.

Edge & Cloud Infrastructure

Edge Native Zero Cloud GPU Docker / NVR Gateway

100% on-premise execution eliminating expensive cloud bandwidth or per-minute video API bills. Easily deployed on dock mini-PCs, NVR gateways, or central servers.

Front-End & Data Storage

Obsidian Void UI LocalStorage Cache JSON Audit Export

Clean Vanilla ES6+ modular architecture, SVG micro-charts, zero heavy framework overhead, automatic evidence snapshot storage, and one-click JSON export.
